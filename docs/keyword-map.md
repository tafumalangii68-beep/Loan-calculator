# Keyword map and information architecture

No keyword tool data was available while building this site, so **no search volumes or difficulty scores are given**. Keywords below are grouped by search intent from the topic itself. Check them with a real keyword tool (Google Search Console after launch, or Keyword Planner, Ahrefs, Semrush) and adjust.

## Primary intent

People searching **"loan calculator"** want a tool first: enter an amount, rate and term and get a monthly payment. They usually want total interest and a schedule as well. The homepage puts the working calculator above the fold and backs it up with explanations.

## Avoiding keyword cannibalization

- **"Amortization schedule calculator"** goes to the homepage, because the tool there produces the schedule. The amortization guide targets the *informational* "how does it work" query and links back to the tool.
- **"Extra payment calculator"** goes to the homepage (the tool). The extra-payments guide covers the "should I / how much do I save" questions.
- Each loan-type page has its own fields (down payment, trade-in, origination fee and APR, student plan scope) and content, so they are not near-duplicates of the homepage.

## Internal linking

- Header: all four loan calculators, Guides, FAQ, About. Footer: every indexable page plus Cookie settings.
- Homepage → all loan calculators and all guides (cards), plus contextual links to the guides and the disclaimer.
- Loan pages → homepage, amortization guide, two related calculators.
- Guides → relevant calculators ("Try it with your own numbers") and the other guides.
- Breadcrumbs on every page except the homepage (with BreadcrumbList structured data).
